# Security Policy

## Supported version

Only the newest GitHub Release is supported with security fixes.

## Reporting

Do not publish vulnerabilities that could change a user's DNS configuration or
affect release artifacts in a public issue. Contact the maintainer privately
through the address listed on the GitHub profile and include the affected
version, reproduction steps, and impact. Do not include secrets or private
network details.

## Release integrity

Official release archives are built by GitHub Actions from commits contained in
`main`. Verify downloads with the SHA256 file attached to the same release.
